# 🛠️ EBM Ferragem — Landing Page Oficial

Landing page moderna, responsiva e otimizada para motores de busca (SEO/GEO) desenvolvida para a **EBM Ferragem**, localizada em Rio Grande - RS.

> 🌐 **Site ao vivo:** [ebm-ferragens.vercel.app](https://ebm-ferragens.vercel.app)

---

## 🎯 Objetivo do Projeto

O objetivo principal desta landing page é facilitar a captação de clientes locais em Rio Grande - RS, direcionando as solicitações de orçamento de forma rápida e prática para o **WhatsApp** da loja.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível com `header`, `nav`, `main`, `section` e `footer`.
- **Tailwind CSS v4:** Estilização moderna e responsiva com tema customizado e suporte a classes utilitárias.
- **Font Awesome:** Ícones vetoriais integrados.
- **AOS (Animate On Scroll):** Animações de entrada e interatividade ao rolar a página.
- **Vercel CLI:** Deploy contínuo e alojamento de alta performance.

---

## 📍 SEO Local & Otimização GEO

O projeto foi construído seguindo as melhores práticas para descoberta local e indexação por Inteligência Artificial:

- [x] **Schema.org (JSON-LD):** Dados estruturados da empresa local (`HardwareStore`) incluindo morada, horários, localização e telefone.
- [x] **Robots.txt & Sitemap.xml:** Orientação para motores de busca e indexação correta das URLs.
- [x] **llms.txt:** Contexto estruturado para motores de IA e assistentes virtuais (ChatGPT, Gemini, Claude).
- [x] **Open Graph & Meta Tags:** Otimizados para partilha em redes sociais e pré-visualização no WhatsApp.
